================================================================================
REQUIREMENT: Double DQN to reduce Q-value overestimation
STATUS: [OK] COMPLETE

Solution:
- Separate action selection (policy network) from evaluation (target network)
- Select: a* = argmax_a' Q_policy(s',a')
- Evaluate: Q_target(s',a*)

Code in src/trading_sdk/services/training.py (_optimize method):

    next_q = target(ns).gather(1, next_actions).squeeze(1)

    epsilon = max(epsilon_end, epsilon - decay)

Over-trading analysis:
- High epsilon early: frequent random trades, high friction
- Decaying epsilon: fewer trades, lower costs, smoother returns
- Balances exploration for market discovery vs. exploitation of learned policy

11. BELLMAN FORMULA DOCUMENTATION IN README
================================================================================
REQUIREMENT: Document Bellman formula with variable explanations
STATUS: [OK] COMPLETE

Formula documented:
    Q(s,a) = E[r + gamma * max_a' Q(s',a')]

Where:
- Q(s,a): Expected cumulative reward from action a in state s
- r: Immediate reward received
- gamma (0.99): Discount factor for future rewards
- s': Next state after taking the action
- a': All possible actions in next state

In practice (batch training):
    Target_i = r_i + gamma * (1 - done_i) * max_a' Q_target(s'_i, a')

Double DQN variant documented:
    Target = r + gamma * (1 - done) * Q_target(s', argmax_a' Q_policy(s',a'))

All formulas in LaTeX notation in README.md Section 6.1

Concrete examples with config values

12. DUELING FORMULA & WHY IT HELPS IN TRADING
================================================================================
REQUIREMENT: Explain Dueling formula and trading benefits
STATUS: [OK] COMPLETE

Formula: Q(s,a) = V(s) + (A(s,a) - mean_a A(s,a))

Variables:
- V(s): Value stream (state value - "how good is this market regime?")
- A(s,a): Advantage stream (action advantage - "which action is best?")
- mean_a A(s,a): Mean advantage (centering for stability)

Why Dueling helps in trading:
1. HOLD action often most reasonable - value stream learns regime profitability separately
2. Price movements small - advantage stream captures subtle action differences
3. Many market regimes - separate streams enable faster convergence
4. Risk-return tradeoff - some actions have similar returns but different risks

Documentation in README.md Section 6.3:
"In stock trading, the action HOLD is often the most reasonable action.
Price movements can be small; action differences may not be obvious.
Dueling DQN explicitly learns state value (is this market regime profitable?)
separately from action advantages (which specific action is better here?)"
